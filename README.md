# بوت المواد الدراسية - دليل التشغيل

## الملفات
- `bot.py` — البوت الرئيسي (لا تحتاج تعديله إلا نادراً)
- `materials.json` — كل موادك وملفاتك (هذا ما ستعدّله دائماً)
- `get_file_id.py` — سكربت مساعد لمعرفة file_id لأي ملف
- `requirements.txt` — المكتبات المطلوبة

## خطوات التشغيل

### 1) تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 2) إنشاء البوت
- تحدث مع `@BotFather` في تليجرام
- أرسل `/newbot` واتبع التعليمات
- انسخ التوكن الذي يعطيك إياه

### 3) ضع التوكن
افتح `bot.py` و `get_file_id.py` وضع التوكن مكان:
```python
BOT_TOKEN = "ضع_التوكن_هنا"
```

### 4) احصل على file_id لكل ملفاتك
- شغّل: `python get_file_id.py`
- أرسل كل ملفاتك (PDF / فيديوهات) للبوت واحداً تلو الآخر
- انسخ الـ file_id الذي يرد به لكل ملف

> ملاحظة: يفضل رفع الفيديوهات والملفات أولاً لأي شات أو قناة خاصة بك في تليجرام حتى تحصل منها على الـ file_id، وتبقى محفوظة على سيرفرات تليجرام بدون أي استضافة إضافية.

### 5) عدّل materials.json
أضف موادك وملفاتك بنفس الشكل الموجود، مثال إضافة ملف جديد:
```json
{
  "title": "المحاضرة 2 - القياسات",
  "file_id": "الصق_file_id_هنا",
  "type": "document"
}
```
- `type` تكون `document` للـ PDF أو `video` للفيديو

لإضافة مادة جديدة بالكامل، انسخ نفس بنية "geodesy" في الملف وغيّر:
- المفتاح (subject_key) بالإنجليزية بدون مسافات
- `title` بالعربية كما تريد أن تظهر
- أضف ملفاتك داخل `lectures` أو `videos`

### 6) شغّل البوت
```bash
python bot.py
```

## للتشغيل الدائم 24/7
ارفع الملفات على استضافة مثل Railway أو Render أو VPS، وشغّل `bot.py` هناك بدلاً من جهازك.
