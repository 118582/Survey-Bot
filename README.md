# بوت المواد الدراسية - النسخة الكاملة

## الملفات
| الملف | الوظيفة |
|---|---|
| `bot.py` | الكود الرئيسي (كله معلّق عليه بالتفصيل) |
| `materials.json` | المواد الدراسية (8 مواد جاهزة، عدّل الأسماء براحتك) |
| `users.json` | يتسجل فيه تلقائياً كل مستخدم يفتح البوت (للإذاعة) |
| `custom_buttons.json` | الأزرار المخصصة اللي تضيفها من لوحة الأدمن |
| `requirements.txt` / `Procfile` | ملفات الاستضافة |

## أول حاجة قبل الرفع
افتح `bot.py` وعدّل في الجزء اللي فوق (قسم 1 - الإعدادات العامة):

1. **القنوات الإجبارية** — دلوقتي فاضية (مفيش اشتراك إجباري). لتفعيلها:
```python
REQUIRED_CHANNELS = [
    "@your_channel_1",
    "@your_channel_2",
]
```
لازم البوت يكون **أدمن في كل قناة** عشان يقدر يتحقق من الأعضاء.

2. **الأدمنية** — انت مسجل بالفعل (`7724699440`). لإضافة أدمن تاني:
```python
ADMIN_IDS = [
    7724699440,
    123456789,   # أدمن جديد
]
```

3. **ترتيب أزرار القائمة الرئيسية** — النمط الحالي `[1, 2, 1, 2, 1, 2, 1]` (زر / زرين / زر / زرين...). غيّره براحتك.

## إجابة سؤالك: "الباقي فين؟"
القائمة الرئيسية دلوقتي فيها 3 أزرار حقيقية بس (المواد، اللغة، والأدمن للأدمن بس)، لأن دي الأقسام اللي وصفتها. سيبتلك مكانين جاهزين في الكود عشان تضيف أي زر جديد بسهولة **من غير ما تكسر حاجة**:

- **من داخل البوت نفسه (الأسهل):** لوحة الأدمن فيها زرار **"🔘 إضافة زر مخصص"** — تكتب اسم الزر (عربي/إنجليزي) وتبعت نص أو ملف، وهو بيظهر في القائمة الرئيسية فوراً لكل المستخدمين، وتقدر تحذفه في أي وقت بزرار **"🔘 حذف زر مخصص"**.

- **من الكود مباشرة (لو عايز تحكم أكتر):** في دالة `build_main_menu` جوه `bot.py`، فيه بلوك معلّق بعنوان:
```python
# 🧩 مكان جاهز لإضافة أزرار تانية يدوياً في الكود مباشرة (اختياري)
```
فك التعليق عن أي سطر واكتب اسمك، وضيف رد الفعل بتاعه تحت في `button_handler` (فيه مكان معلّم بنفس الطريقة). نفس الفكرة موجودة في `admin_menu_keyboard()` لو عايز تزود زرار إدارة جديد بلوحة الأدمن.

## رحلة المستخدم بالكامل
1. `/start` → لو فيه قنوات إجبارية ومش مشترك، تظهر أزرار الاشتراك + زرار "اشتركت"
2. بعد التأكد من الاشتراك → اختيار اللغة (عربي / English) — أول مرة بس، بعدها بيتذكرها
3. القائمة الرئيسية:
   - 📚 المواد الدراسية → اختيار مادة → 3 أقسام (ملخصات PDF / فيديوهات / شرح) → قائمة ملفات → إرسال الملف
   - 🌐 تغيير اللغة → يقدر يغيّرها في أي وقت
   - ⚙️ لوحة الأدمن (تظهر بس للأدمن)

## لوحة الأدمن بالكامل
- ➕ إضافة مادة (بيسألك بالعربي والإنجليزي + معرف قصير)
- ➕ إضافة قسم لمادة موجودة
- ➕ إضافة ملف (يدعم PDF، فيديو، صورة، صوت، رسالة صوتية، GIF — تبعته مباشرة وهو ياخد الـ file_id تلقائي)
- 🗑 حذف ملف / حذف قسم / حذف مادة كاملة
- 🔘 إضافة/حذف زر مخصص في القائمة الرئيسية
- 📢 إذاعة رسالة لكل المستخدمين المسجلين (نص أو أي نوع ملف)
- 📦 نسخة احتياطية (ZIP فيه كل ملفات JSON + bot.py)
- 📋 عرض كل شيء (كل المواد والأقسام وعدد الملفات والمستخدمين)

## خطوات الرفع
1. حط كل الملفات في مجلد واحد باسم البوت
2. ارفعهم على GitHub
3. Railway → New Project → Deploy from GitHub repo
4. من Variables ضيف `BOT_TOKEN` بتوكنك
5. تأكد إن البوت أدمن في أي قناة حطيتها في `REQUIRED_CHANNELS`

## ملاحظة أمان
التوكن كان مكتوب صريح في نسخة قديمة من الملف اللي بعتهولي — احتياطاً، اعمل **Revoke** له من BotFather وهات توكن جديد وحطه في Variables على Railway، مش في الكود مباشرة.
